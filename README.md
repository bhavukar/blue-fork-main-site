# Blue Fork

Excellence in simplicity.

## Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Engine**: [Three.js](https://threejs.org/) via [@react-three/fiber](https://github.com/pmndrs/react-three-fiber)
- **3D Components**: [@react-three/drei](https://github.com/pmndrs/drei)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- **3D Blue Fork**: A metallic blue utensil fork in a clean, interactive 3D environment.
- **Minimalist UI**: Professional and clean interface with no jargon.
- **Investor Relations**: Dedicated access for corporate stakeholders.

## Deployment

The production build is optimized and ready for deployment via the `dist` folder.
